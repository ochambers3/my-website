# owenchambers.ca

Personal site for Owen Chambers. Single-page static HTML/CSS.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## Custom domain

`CNAME` is set to `owenchambers.ca`. Point the domain at whatever host you use for this folder (GitHub Pages, Netlify, Cloudflare Pages, etc.).
